--- MINIBUFFER & SEARCH (VERTICO + CONSULT + ORDERLESS) ---
M-x             execute-extended-command   Vertical command list
C-x b           consult-buffer             Live-preview buffer switch
C-s             consult-line               Fuzzy search in current buffer
C-c q           consult-grep               Live project-wide search
M-g i           consult-imenu              Jump to symbol in current file
M-g I           consult-imenu-multi        Jump to symbol in ANY open file
M-y             consult-yank-pop           Visual kill-ring history
C-n / C-p       vertico-next/previous      Navigate lists

--- UI & CONTEXT (EMBARK + MINIMAP + ELDOC-BOX) ---
C-.             embark-act                 "Context Menu" for point/candidate
C-c m           minimap-mode               Toggle VS Code-style mini-view
C-c t           treemacs                   Toggle File Explorer sidebar
C-c h           eldoc-box-help-at-point    Function/symbol documentation
C-c d           eldoc                      Documentation in a dedicated window
M-next          Alt-PgDn                   Page the eldoc child window
M-prev          Alt-PgUp                   Page the eldoc child window


--- INTELLIGENCE (LSP-MODE) ---
M-.             xref-find-definitions      Jump to definition
M-,             xref-go-back               Jump back through xref stack
M-?             xref-find-references       Find all usages (via LSP)
s-l r r         lsp-rename                 Type-safe rename across project
s-l a a         lsp-execute-code-action    LSP Fix-its (Quick Fix menu)
s-l w r         lsp-restart-workspace      Restart LSP server
s-l w q         lsp-shutdown               Shutdown all LSP servers

(s-l -> Super L -> Windows key L -> C-c C-l)

M-,             xref-go-back               Jump back
M-?             xref-find-references       Find all usages (LSP)

C-c C-c a       eglot-code-actions         LSP Fix-its (Quick Fix menu)

--- CARGO & BUILD ENGINE (RUSTIC) ---

C-c C-c C-b     rustic-cargo-build         Full project compilation

--- COMPLETION (CORFU) ---

TAB             corfu-insert               Insert selected candidate
ESC             corfu-quit                 Close completion popup
